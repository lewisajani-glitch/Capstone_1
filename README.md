Connecticut In-Store Sales Analysis

Project Overview

This project analyzes in-store sales data from Connecticut between 2022 and 2025 to identify sales trends, compare store performance, and understand product category performance.

Tools Used

SQL (MySQL): Data querying, filtering, joins, and aggregations.

Excel: Data analysis and visualization.
